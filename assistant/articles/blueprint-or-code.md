- **Grafo:** você liga nós com o mouse. Ótimo para começar e para quem pensa visualmente.
- **Código:** Real (a da engine, simples como Python), C#, Python ou C. Ótimo para lógica longa.
- **São a mesma coisa por baixo:** um script vira um grafo de Grafo e roda no mesmo código nativo. Dá para misturar (um Grafo pode herdar de um script).
