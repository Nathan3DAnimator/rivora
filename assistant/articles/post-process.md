--- pt
- **Ator > Adicionar > Post Process Volume** muda a imagem dentro dele (ou no nível todo, com Unbound). [Adicionar](add:PostProcess)
- Exposição (automática como uma câmera, com compensação), bloom, cor, saturação, contraste, vinheta.
- Por Grafo: **Set Post Process Float / Tint / Weight** (um flash de dano, a visão noturna).
--- en
- **Actor > Add > Post Process Volume** changes the image inside it (or the whole level, with Unbound). [Add one](add:PostProcess)
- Exposure (automatic like a camera, with compensation), bloom, color, saturation, contrast, vignette.
- From a Graph: **Set Post Process Float / Tint / Weight** (a damage flash, night vision).
--- es
- **Actor > Añadir > Post Process Volume** cambia la imagen dentro de él (o de todo el nivel, con Unbound). [Añadir uno](add:PostProcess)
- Exposición (automática como una cámara, con compensación), bloom, color, saturación, contraste, viñeta.
- Desde un Grafo: **Set Post Process Float / Tint / Weight** (un destello de daño, visión nocturna).
