## Um projeto novo
1. Abra **Arquivo > Novo Projeto...** (ou o Project Browser, que aparece ao abrir o editor). [Mostrar onde](show:File>New Project...)
2. Escolha um modelo: **Terceira Pessoa**, **Primeira Pessoa**, **Visão de Cima** ou **Física**. Também há jogos de demonstração (RPG, Terror, Luta) para estudar.
3. Dê um nome e uma pasta e crie. O projeto abre com um nível pronto para jogar.

## Depois
- **Alt+P** joga no editor. Veja [Jogar no editor](article:play-in-editor).
- Os assets ficam na pasta **Content** do projeto. Veja [Gaveta de Conteúdo](article:content-drawer).
- **Trocar de projeto** (Arquivo > Abrir Projeto, ou um projeto novo) fecha todos os editores de asset abertos. Se o nível ou algum asset tiver mudanças não salvas, a engine pergunta antes: **Salvar e Abrir**, **Não Salvar** ou **Cancelar** (com a lista do que mudou). Os plugins do projeto antigo são desligados; os da engine continuam.

## A new project
1. Open **File > New Project...** (or the Project Browser that shows when the editor starts). [Show me where](show:File>New Project...)
2. Pick a template: **Third Person**, **First Person**, **Top Down** or **Physics**. There are demo games too (RPG, Horror, Fighting) to learn from.
3. Give it a name and a folder and create it. The project opens with a level ready to play.

## Next
- **Alt+P** plays in the editor. See [Play in the editor](article:play-in-editor).
- The assets live in the project's **Content** folder. See [Content Drawer](article:content-drawer).
- **Switching projects** (File > Open Project, or a new project) closes every open asset editor. When the level or an asset has unsaved changes, the engine asks first: **Save and Open**, **Don't Save** or **Cancel** (with the list of what changed). The old project's plugins are turned off; the engine's stay.

## Un proyecto nuevo
1. Abre **Archivo > New Project...** (o el Project Browser que aparece al iniciar el editor). [Muéstrame dónde](show:File>New Project...)
2. Elige una plantilla: **Third Person**, **First Person**, **Top Down** o **Physics**. También hay juegos de demostración (RPG, Horror, Fighting) para aprender.
3. Ponle un nombre y una carpeta y créalo. El proyecto se abre con un nivel listo para jugar.

## A continuación
- **Alt+P** juega en el editor. Consulta [Jugar en el editor](article:play-in-editor).
- Los assets viven en la carpeta **Content** del proyecto. Consulta [Cajón de contenidos](article:content-drawer).
- **Cambiar de proyecto** (Archivo > Abrir proyecto, o un proyecto nuevo) cierra todos los editores de assets abiertos. Si el nivel o algún asset tiene cambios sin guardar, el motor pregunta antes: **Guardar y abrir**, **No guardar** o **Cancelar** (con la lista de lo que cambió). Los plugins del proyecto anterior se desactivan; los del motor siguen.
